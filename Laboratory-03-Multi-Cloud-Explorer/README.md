# Laboratory 03 – Multi-Cloud Explorer

## Mission Overview

This laboratory explores Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The activity compares their services and identifies appropriate cloud solutions for different business scenarios.

## Checkpoint 7 – Killercoda Linux Investigation

### System Information

- **Operating System:** Ubuntu 24.04
- **CPU Information:** Obtained using `lscpu`
- **Memory:** Obtained using `free -h`
- **Disk Space:** Obtained using `df -h`

### Cloud Migration

If this Linux server were migrated to the cloud, it could be hosted using:

- **AWS:** Amazon EC2
- **Azure:** Azure Virtual Machines
- **GCP:** Google Compute Engine

These services provide virtual machines that can run Linux operating systems and cloud workloads.
