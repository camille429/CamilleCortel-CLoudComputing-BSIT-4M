# Google Cloud Platform (GCP) Research

## 1. Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform developed by Google. It provides infrastructure and services for computing, storage, databases, networking, analytics, artificial intelligence, and machine learning.

## 2. Global Infrastructure

GCP uses a global infrastructure made up of Regions and Zones. This allows applications and services to operate across different geographic locations while providing scalability and reliability.

## 3. Cloud Management Console

The Google Cloud Console is a web-based interface used to manage Google Cloud resources and services. It allows users to create projects, configure resources, monitor applications, and manage cloud services.

## 4. Four GCP Services

### Compute Engine

Compute Engine provides virtual machines that can be used to run applications and workloads.

### Cloud Storage

Cloud Storage provides scalable object storage for files, backups, media, and other data.

### Cloud SQL

Cloud SQL is a fully managed relational database service.

### Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service used to deploy and manage containerized applications.

## 5. Three Advantages

- Strong artificial intelligence and machine learning capabilities
- Powerful data analytics services
- Global and scalable infrastructure

## 6. Typical Use Cases

GCP can be used for:

- Artificial intelligence and machine learning
- Data analytics
- Web applications
- Containerized applications
- Big data processing
- Cloud storage
- Software development
