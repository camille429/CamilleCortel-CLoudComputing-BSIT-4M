# Mission Reflection

## Multi-Cloud Explorer Reflection

This laboratory activity helped me understand the differences between **Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP)**. Before doing this activity, I only knew that cloud computing allows people to use computer resources through the internet. After completing the research, I learned that each cloud platform has different services, features, and advantages.

I learned that **AWS** offers a wide variety of cloud services. It can be used for storage, databases, servers, applications, and many other purposes. **Microsoft Azure** is a good choice for organizations that already use Microsoft products such as Windows Server, Microsoft 365, and Active Directory. **Google Cloud** is known for its strong services in artificial intelligence, machine learning, data analytics, and Kubernetes.

I also learned that choosing a cloud platform depends on the needs of an organization. For example, a **startup** may choose AWS because it is flexible and can grow with the business. A **university** that uses Microsoft products may choose Azure because of its strong Microsoft integration. An **AI research company** may choose GCP because of its AI and machine learning services. A **global e-commerce company** may choose AWS because it can support many users and handle large workloads.

The **Killercoda Linux investigation** also helped me understand how traditional servers can be used in cloud computing. Linux servers can be hosted using services such as Amazon EC2, Azure Virtual Machines, or Google Compute Engine.

Overall, this mission taught me that there is no single best cloud platform for everyone. The best choice depends on the organization's **budget, technology, needs, and goals**. This activity improved my understanding of cloud computing and how it is used by different organizations.
