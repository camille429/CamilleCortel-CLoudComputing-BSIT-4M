Microsoft Azure Research
1. Brief Overview

Azure is a cloud platform by Microsoft for storing data and running applications.

2. Global Infrastructure

Azure has Regions and Availability Zones that help keep services fast and reliable.

3. Cloud Management Console

Azure Portal is used to manage Azure services.

4. Four Azure Services
   
Virtual Machines – Virtual computers

Blob Storage – Stores files and data

SQL Database – Manages databases

Azure Functions – Runs code without a server
