Amazon Web Services (AWS) Research
1. Brief Overview

Amazon Web Services (AWS) is a cloud platform from Amazon. It provides online services for storing data, running applications, and managing websites.

2. Global Infrastructure

AWS has Regions and Availability Zones around the world. These help make AWS services faster, reliable, and available.

3. Cloud Management Console

The AWS Management Console is a website where users can manage and control AWS services.

4. Four AWS Services

Amazon EC2 – Provides virtual computers or servers for running applications.

Amazon S3 – Used to store files, photos, documents, and other data.

Amazon RDS – Used to create and manage databases.

AWS Lambda – Runs code without needing to manage a server.

5. Three Advantages
   
Many cloud services to choose from

Can handle small or large workloads

Flexible and easy to scale

6. Typical Use Cases

AWS can be used for:

*Hosting websites

*Creating applications

*Storing files and data

*Managing databases

*Artificial intelligence

*Running applications without servers
