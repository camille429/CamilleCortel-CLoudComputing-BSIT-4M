# Laboratory 06 — Cloud Deployment Engineer

## Mission Overview
This lab demonstrates how to deploy a **multi-tier architecture** using Docker and Docker Compose. We built a fully functional Nextcloud instance with a dedicated MariaDB database — running as separate, coordinated containers.


## Objectives
- ✅ Understand multi-tier architecture design
- ✅ Write a production-ready `docker-compose.yml` file
- ✅ Deploy web and database services as separate containers
- ✅ Use environment variables for secure configuration
- ✅ Access the application through a published port
- ✅ Document and reflect on the deployment process
