# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?
I believe **Compute** is the most critical component. Storage keeps data and networking connects things, but compute is what actually does the work — running code, processing data, and serving applications. Without compute, there is no engine to power anything in the cloud.

## 2. How does Linux support cloud computing?
Linux is the dominant operating system in the cloud — almost all cloud servers run Linux because it is lightweight, stable, secure, open-source, and highly customizable. It powers virtual machines, containers, and cloud services worldwide. This activity on KillerCoda showed me exactly how cloud instances look and behave.

## 3. Why is technical documentation important before deploying infrastructure?
Documentation ensures clarity, consistency, and reproducibility. If you deploy without documentation, nobody knows what exists, why choices were made, or how to maintain it later. Good documentation prevents confusion and speeds up troubleshooting.

## 4. What new skills did you learn?
I learned how to inspect a Linux system using terminal commands, how to match equivalent services across AWS, Azure, and GCP, how to create proper Markdown documentation, and how to diagram a simple cloud architecture.

## 5. How has your GitHub Cloud Computing Portfolio improved?
My portfolio now has a professional structure: organized folders, meaningful Markdown files, proper documentation, and visual evidence through screenshots. It serves as a growing record of what I can do — something I can show to future employers.
