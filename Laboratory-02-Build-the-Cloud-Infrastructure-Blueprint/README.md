# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on understanding the fundamental components of cloud infrastructure. It involves investigating a Linux cloud environment, identifying compute, storage, networking, and operating system resources, comparing major cloud providers, and designing a simple cloud infrastructure blueprint.

## Objectives

- Investigate the resources available in a cloud-based Linux environment.
- Identify the major components of cloud infrastructure.
- Understand the role of compute, storage, networking, and operating systems.
- Compare equivalent services from AWS, Microsoft Azure, and Google Cloud Platform.
- Design a simple cloud infrastructure architecture.
- Document the investigation and findings using Markdown.
- Organize and maintain cloud computing activities in a GitHub portfolio.

## Tools Used

- GitHub
- KillerCoda Playground
- Linux Terminal
- Git
- Markdown
- Web Browser

## Laboratory Checkpoints

### Checkpoint 1 – Expand Your Cloud Portfolio

Create and organize the Laboratory 02 folder inside the existing GitHub cloud computing repository.

### Checkpoint 2 – Investigate the Cloud Server

Investigate the Linux server's operating system, kernel, CPU, memory, storage, hostname, and network information.

### Checkpoint 3 – Identify Cloud Infrastructure Components

Identify and explain compute, storage, networking, and operating system resources.

### Checkpoint 4 – Research the Major Cloud Providers

Compare AWS, Microsoft Azure, and Google Cloud Platform and their equivalent infrastructure services.

### Checkpoint 5 – Design a Simple Cloud Infrastructure

Create a basic cloud architecture containing a user, internet connection, network, compute resource, and storage resource.

### Checkpoint 6 – Technical Documentation

Document the investigation, commands, findings, skills learned, and challenges encountered.

### Checkpoint 7 – Mission Reflection

Write a reflection describing what was learned throughout the laboratory activity.

## Conclusion

This laboratory will provide practical experience in understanding cloud infrastructure, Linux server resources, cloud provider services, system documentation, and basic cloud architecture design.
